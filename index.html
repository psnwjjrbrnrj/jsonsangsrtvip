Cách tìm file draft_content.json

CapCut lưu trữ toàn bộ nội dung phụ đề trong file draft_content.json bên trong thư mục dự án của bạn:

Windows Đường dẫn CapCut PC
Nhấn tổ hợp phím Win + R, dán đường dẫn trên và nhấn Enter để mở thư mục.
Windows Đường dẫn JianYing (CapCut Trung Quốc)
macOS Đường dẫn CapCut Mac
Mẹo: Trong thư mục dự án, tìm thư mục có tên video của bạn, bên trong sẽ có file draft_content.json (hoặc draft_info.json trên Mac). Kéo thả file đó vào đây!
